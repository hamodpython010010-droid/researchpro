# ResearchPro

1. ثبّت Node.js 20 أو أحدث.
2. افتح CMD داخل هذا المجلد.
3. نفّذ: npm install
4. انسخ `.env.example` إلى ملف اسمه `.env`.
5. ضع مفتاح OpenAI في OPENAI_API_KEY.
6. نفّذ: npm start
7. افتح: http://localhost:3000

الزر الرئيسي يجبر Responses API على استخدام Web Search، ثم يكتب البحث اعتمادًا على النتائج. لا تضع المفتاح داخل public/index.html ولا تشاركه.
