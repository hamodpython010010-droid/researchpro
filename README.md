# ResearchPro — Gemini Free

نسخة ResearchPro التي تستخدم Gemini API بدل OpenAI.

1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env`.
4. ضع مفتاح Gemini في `GEMINI_API_KEY`.
5. نفّذ `npm start`.
6. افتح `http://localhost:3000`.

الموديل الافتراضي: `gemini-2.5-flash`. يستخدم Google Search grounding عند إنشاء البحث. لا ترفع ملف `.env` إلى GitHub ولا تشارك المفتاح.
